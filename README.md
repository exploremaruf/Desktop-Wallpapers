# Desktop-Wallpapers


This repository contains a curated collection of high-resolution desktop wallpapers.  
All images are optimized for modern displays and suitable for Windows, macOS, and Linux.

## Features
- High-quality wallpapers (mostly 4K or higher)
- Nature, Abstract, Minimal, Sci-Fi, and Space themes
- Organized for easy browsing

## How to Use
1. Open `/home/runner/work/Desktop-Wallpapers/Desktop-Wallpapers/index.html` in your browser.
2. Browse or search wallpapers in the gallery.
3. Click a wallpaper to preview it.
4. Use the **Download** button to save it.
